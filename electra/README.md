# QA Manager — Electron

Fontes da versão 1.8.6. Backend Spring Boot/Java 21 em `backend/` e frontend React/TypeScript/Vite em `frontend/`.
Leia o [guia na raiz](../README.md) para configurar ambiente, banco e credenciais.

Para testar o backend: `cd backend` e `mvn test` (ou `mvnw.cmd test` no Windows).
Para testar/compilar o frontend: `cd frontend`, `npm ci`, `npm run build`.
